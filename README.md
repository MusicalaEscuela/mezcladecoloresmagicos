# Mezcla de Colores Mágicos · Glow Up

Versión mejorada del minijuego educativo de mezcla de colores.

## Qué se mejoró

- Mecánica jugable con gotas y recetas claras.
- Retos progresivos por nivel.
- Pistas útiles sin romper totalmente el juego.
- Feedback específico: faltan gotas, sobran gotas o hay que cambiar pigmentos.
- Recetas descubiertas guardadas en el navegador.
- Mejor puntaje guardado con `localStorage`.
- Interfaz responsive, más clara y más llamativa para niños.
- Sin dependencias externas ni módulos, para que pueda abrirse directo desde `index.html`.

## Cómo usar

1. Abre `index.html` en el navegador.
2. Haz clic en los pigmentos para agregar gotas.
3. Valida la mezcla.
4. Descubre recetas y completa los 10 retos.

## Atajos

- 1: Rojo
- 2: Amarillo
- 3: Azul
- 4: Blanco
- 5: Negro
- Enter: Validar
- Backspace: Quitar última gota
- Escape: Limpiar mezcla
